\# 1. Purpose



This document defines the complete visual language of TARDIS Den.



Every screen, interaction, animation, and object should follow this design system.



The objective is to create one visually consistent environment where every element feels like it belongs inside the same room.



\---



\# 2. Design Philosophy



The interface should disappear.



Objects should feel tangible.



Every visual decision should support immersion.



The administrator should never feel like they are using a dashboard.



Instead, they should feel present inside a carefully designed observatory-bedroom.

\# 20. Accessibility

4.5:1



Keyboard accessible



Visible focus states



Reduced motion support

Large interaction targets



\---



\# 21. Performance Guidelines



Lazy load heavy assets



Optimize textures



Use SVG where appropriate



Compress images



Avoid unnecessary re-renders



Target 60 FPS animations



\---



\# 22. Design Rules



Every new UI element must answer:



Does it feel like it belongs inside the room?



Does it match the existing material language?



Does it reduce visual noise?



Does it improve immersion?



Would it still look appropriate five years from now?



If the answer is "No", redesign before implementation.



\---



\# Final Principle



The administrator should remember the room—not the interface.



The design succeeds when technology becomes nearly invisible and the environment itself becomes the experience.
